## Overview

Baby Audio SubCulture generates deep, powerful sub bass frequencies through synthesis and harmonic extension, adding low-end weight to kick drums, bass, and other sources.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Baby Audio SubCulture** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Sub Synth** | Sine wave sub oscillator tuned to the input pitch for clean sub generation |
| **Harmonic Extend** | Adds harmonics above the fundamental for audibility on small speakers |
| **Transient Punch** | Transient click layer enhances the attack of kick and bass hits |
| **Sidechain** | Optional sidechain input ducks the sub against kick drum for clarity |
